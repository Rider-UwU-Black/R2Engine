PS2 PERFORMANCE CHECKPOINT - SEPTEMBER 2, 2026
=============================================

[DONE] Native game export and playtesting are beyond the initial probe stage.
  - Bootable ISO workflow has been exercised in PCSX2 and on a real PS2 via
    PSBBN/OPL. Recent detailed performance measurements below are PCSX2 results.
  - Scene changes, animated characters, controller menus, interactions/dialogue,
    and imported game fonts have been exercised during iterative testing.

[DONE] Stable renderer optimization pass
  - One XGKICK per bounded 24-triangle VU job; non-overlapping VU memory banks.
  - Up to 16 jobs per VIF DMA chain, with compatibility for older larger meshlets.
  - Per-object packed vertex scratch cache; aligned 128-bit copies into job inputs.
  - Removed redundant per-job input clearing after auditing VU reads and testing
    all 1,536 supported vertex/triangle-count combinations with reused buffers.
  - Object/camera transforms composed once per object; shared reciprocal depth.
  - Bone-weight lookup replaces repeated byte-to-float divisions during skinning.
  - Fog-range reciprocal calculated once per frame; alpha clamped once per object.
  - Numerical transform tests and generated EE assembly checks support these changes.
  - User testing reports stable rendering after the accepted changes. Earlier VU
    holes/flashes/browser exits were not accepted as a usable checkpoint.
  - The slower per-vertex blended-matrix skinning experiment was reverted.

[DONE] Measured stress-test baseline established
  - With the unoptimized high-poly body enabled, latest comparable readout:
    SKN 14.6 ms, VTX 11.1 ms, TRI 2.8 ms, PREP 6.9 ms,
    SEND 1.4 ms, SET 0.2 ms, ALL 37.7 ms; displayed FPS about 20 in this view.
  - With that body disabled: SKN 2.8 ms, VTX 1.9 ms, TRI 4.0 ms,
    ALL 9.3 ms and displayed 60 FPS in the tested scene/view.
  - These are scene/view-specific measurements, not a guarantee of 60 FPS for
    every level or on real hardware. ALL measures rendering, not the entire game
    frame. PREP/SEND/SET further explain time within ALL; do not add them to ALL.
  - Keep the current native profiler available for future before/after comparisons.

[DEFERRED] Final main-character body optimization (game asset work)
  - The high-poly body is the intended character's unfinished base model and a
    useful worst-case test. It is deliberately not optimized yet.
  - Later target roughly 5-6k polygons, then measure actual exported vertex count
    and bone influences as well as triangle count. No automatic reduction now.
  - Re-enable and retest it when the optimized asset is ready; no reimport or
    art changes are required to keep the current engine checkpoint.
